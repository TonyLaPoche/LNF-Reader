# LNF-Reader

PWA mobile pour lire des light novels et web novels au format EPUB.

Les fichiers `.epub` et `.pdf` se chargent depuis les téléchargements du téléphone. Le livre et la position de lecture restent sur l’appareil (IndexedDB pour le fichier, `localStorage` pour la reprise).

En local : `npm install` puis `npm run dev`, ouvrir `http://localhost:5173/LNF-Reader/`.
